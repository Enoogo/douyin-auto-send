# 抖音自动续火(Chrome 插件)

每天定时打开抖音网页版的消息面板 → 逐个给**多位好友**发送消息(默认内容 `test`,回车发送),维持聊天火苗(续火)。

## 功能

- ⏰ 每天定时(默认 10:00,可改),`chrome.alarms` 保证到点触发
- 👥 **好友多选**:下拉列表从抖音「消息」会话列表拉取好友,可勾选多位
- ⌨️ 保留**原始手动输入**:填名字(多个用逗号/顿号分隔),与勾选合并生效
- 🛡 防发错人:发送前校验聊天窗标题确为目标好友;当前停在他人的聊天窗时自动先退回会话列表
- 🔍 好友不在最近列表时,自动用面板内搜索框兜底搜索
- 📋 执行结果逐位好友显示(成功 ✅ / 失败原因 ❌),图标短暂显示 ✓/✗ 角标

## 页面机制(2026-09-07 在 www.douyin.com 实测)

| 步骤 | 页面元素 |
|---|---|
| 打开消息面板 | 右上角 `[data-e2e="im-entry"]`(弹层 `[data-e2e="im-dialog"]` 预渲染但隐藏) |
| 会话列表 | `[data-e2e="conversation-item"]`,首行=好友名 |
| 输入框 | `[data-slate-editor="true"]`(Slate 编辑器,占位"发送消息") |
| 发送 | 回车即发送,无独立发送按钮 |

⚠️ 抖音的"消息"入口和会话项**忽略脚本合成点击**(`el.click()`/`dispatchEvent` 无效,校验 `isTrusted`),所以插件通过 `chrome.debugger`(CDP `Input` 域)注入浏览器级可信鼠标/键盘事件 —— 这是 manifest 里需要 `"debugger"` 权限的原因,安装时 Chrome 的权限提示属正常现象。

## 安装 / 更新

1. 打开 `chrome://extensions`,右上角开启**开发者模式**
2. 点**加载已解压的扩展程序**,选择本文件夹(`douyin-auto-send`)
3. 已装过旧版(v1.0)的话:在此页找到旧卡片,点 **⟳ 刷新** 即可更新(数据自动保留,单好友配置会迁移成好友列表)
4. 首次使用:先手动打开抖音网页版并**登录**,然后在插件弹窗里点「🔄 从抖音会话列表拉取」,勾选要续火的好友(或直接在手动输入框填名字)

## 使用

- 弹窗里:设置时间 / 消息内容 / 勾选好友或手动输入 → **保存设置**
- 点「立即发送一次」随时测试;每位好友的执行结果逐行显示
- 每日到点后:扩展自动复用或新开抖音标签页 → 打开消息面板 → 逐个好友:进入会话 → 输入 → 回车 → 校验 → 切下一个

## 已知限制

- 需要抖音网页版保持登录(偶尔要求重新扫码)
- 好友需与你**聊过至少一次**才会出现在消息会话列表(抖音私信规则);手动输入的名字不受此限,但同样需要会话存在
- 浏览器关闭时定时无法触发(扩展只能在浏览器运行时工作)
- 页面改版导致 `data-e2e` 选择器失效时,需同步更新 `content.js`

## 合规提醒

- 自动化发消息通常违反抖音平台规则,有**风控、限流、封号**风险;批量"续火"刷活跃更容易被识别,请自担风险
- 请只对你自己的账号操作,且对方知情同意;不要对不愿意接收的人发
- 脚本只在你自己的浏览器、自己的登录态下运行,不采集、不上传任何数据
